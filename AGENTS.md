# Agent Rules

1. Work from one Linear issue and one explicit experiment objective.
2. Delegate bounded tasks only; state inputs, outputs, files and acceptance checks.
3. Keep domain logic independent from providers and presentation.
4. Apply SOLID, DRY and KISS with readable names and small public interfaces.
5. Add tests for behavior and a reproducible command for every claim.
6. Write run artifacts before reporting success.
7. Preserve failures and rejected variants.
8. Never expose secrets or raw chain-of-thought.
