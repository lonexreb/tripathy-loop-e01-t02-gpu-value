# Experiment Protocol

Before running:

1. State the question and falsifiable hypothesis.
2. Freeze the baseline, primary metric, dataset version and cutoff.
3. Set compute, time and dollar budgets.
4. Define seeds, repeated trials and the stop condition.
5. Define what evidence would reject the idea.

After running:

1. Save machine-readable metrics and environment identity.
2. Compare with the same baseline and budget.
3. Report uncertainty, latency, cost and failures.
4. Decide keep, reject, revise or stop.
5. Link commit, Linear issue, run ID and artifact path.
